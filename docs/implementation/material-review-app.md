# 素材与问题回顾 App 实现说明

## 实施授权与基线

用户在完成既有设计讨论后明确要求：自动完成其余待定工作，随后实现、验证、审查并提交，完成实现后才停止。因此本轮由代理完成导航选择、兼容方案、测试接口选择及代码审查基准，不再逐项等待人工回答。此前已确认的决策继续有效，尤其不要求用户听音。

规范来源：[产品地图](https://github.com/al123xiaaaa/subtitle_llm/issues/1) 及其中七个子议题。代码审查固定点为本轮开始时的 HEAD：`d64a52151321eb4a0a12b6d6d18d8dd6374f7ff3`；已有工作区改动另存快照，避免误覆盖。生产实现提交到当前分支。

## 导航选择

已比较三种模拟原型：素材工作台、任务时间线、复核队列优先。选择素材工作台：素材库作为入口，素材详情内先选语言、再选版本，结果、问题回顾、修改历史分区。运行任务有独立可返回的进度入口；工具和设置保留入口。时间线会放大任务记录而削弱素材关系；复核队列优先会使默认自动完成的用户首先面对疑点。

一次性原型位于独立本地分支 `codex/prototype-material-review` 的 `electron/renderer/app-prototype.html`，不会混入生产代码。验证使用模拟数据和隐藏浏览器；这不是用户亲自体验或真实模型质量验证的声明。

## 兼容方案

- 在当前 SQLite 数据库中增加素材、版本、修改历史、检查记录、产物与资源记录，不清空已有任务或文件。
- 首次迁移前备份；采用可重复执行的关联补全。可靠的视频标识、精确来源和明确关联用于归并，标题不能作为唯一身份。不能确定的旧任务保持独立并显示来源待确认，允许显式关联。
- 保留旧任务标识与配置恢复语义。没有完整译文的任务展示已完成部分，不因状态字符串或文件存在而宣称完整。
- 无法恢复的历史模型来源、检查记录、文件生成依据显示未知；不补造历史证据。被覆盖的文件不能据现有文件还原多个旧版本。
- CLI、桌面和 TUI 共用持久化的字幕、人工保护和复核记录。桌面为主要问题回顾入口，TUI 继续可选使用，不强制弹出终端。
- 新任务输出使用独立路径，局部编辑形成修改历史；旧产物保持其生成依据，不随编辑静默覆盖。

## 测试接口

按用户对自动完成决策的授权，采用以下公开接口做逐项红绿验证：

1. 素材与复核仓库公开方法：迁移、归并、版本选择、检查失效、编辑、保护、冲突撤销、产物快照和预算预留。使用临时 SQLite 和文件，不碰实际用户数据库。
2. 翻译服务与 CLI：用已注入的外部模型替身验证首轮与额外处理、失败保留、任务恢复、追加操作和结果输出；不依赖内部函数调用顺序。
3. 桌面 IPC 与页面交互：素材、版本、问题回顾、编辑和导出通过真实公开入口验证，外部网络和模型服务可替换，持久化链路实际执行。

聚焦测试与类型检查随修改运行；最终运行完整 Python 和桌面测试，再按 code-review 技能分别审查规范与设计符合性。

## 实现落点与边界

- `src/subtitle_llm/workspace/` 统一处理素材、版本、复核、内容变更、用量与快照；桌面经本地 `workspace` JSON 命令调用，与翻译管线共用任务数据库。
- 自动追加额度为首轮翻译与初检的可靠 token 用量的 30%，排除摘要和估算用量；预留覆盖核验、生成、验收，失败且用量不明时继续占用预留。每组重叠范围最多一轮自动操作。
- Jev 核验和验收概率门槛为 0.9，不能解释为正确率保证。源文不确定、范围不完整或改善证据不足时不自动采用；翻译仍由所选生成模型完成。
- 系统重新识别单次最多 120 秒，结果须通过上下文和时间检查，采用后创建派生任务；没有音视频证据或仍不确定时保留候选，无需人工听音。
- 缺少有效译文的范围不能因人工保留、时间编辑或任务执行结束而变成完整；部分导出保留时间轴并列明缺失行。
- 旧数据库升级前备份并保留旧表，升级中断可回滚重试。当前内容与检查历史独立保存，输出采用冻结快照并原子创建新文件。
- 验证使用临时数据库、真实桌面 IPC 与外部模型替身。本轮不会把模拟模型验证宣称为真实视频翻译质量验收，也未调用付费模型。


## 审查修正

- 书面规范：schema 4 纳入既定迁移；译文与时间修改分别记录并可独立撤销。
- 边界建议：素材身份统一由后端计算；跨表同步集中到存储接口，版本派生不再穿透私有事务方法。
- 设计缺陷：修复续跑内容更新的修订号、追加操作的版本绑定、检查覆盖计算、旧疑点失效、原文回退完整性与空译文撤销。
- 系统重新识别同时预留相关翻译和验收，全部通过后才创建派生版本，并指向原追加操作的用量记录。
- 补齐转写与语义检查默认设置、已知缺少 Jev 配置时的继续选择、累计已知用量，以及独立下载/转写结果回到素材库。
