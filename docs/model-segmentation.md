# 模型断句与翻译

ASR 来源默认在一次模型调用中完成断句和翻译。输入不再先按 84 字符切成固定字幕；模型看到连续原文、可引用的词/字位置和紧凑的 ASR 时间窗口，返回每条字幕的结束位置与译文。

```json
[{"end":18,"text":"模型会被加载到 GPU 显存中。"},{"end":35,"text":"接下来看看推理过程。"}]
```

开始位置由上一条结束位置推得。程序校验连续覆盖、位置有效性和非空译文，从源文恢复文本并映射时间，不根据短尾阈值再次改变模型选择的切点。英文按词提供位置，无空格文字按字提供位置；这些位置不是预先决定的字幕边界。

当前协议 v2 在每个请求内从 1 编号，包括局部补齐请求。返回值立即映射到全片位置，缓存、时间和复核合并仍使用稳定的全片位置。提示要求每条译文只表达自己的源文范围；需要调整目标语言语序时，由模型选择能完整表达两种语言的共同片段，不把译文含义挪到邻条。

## 启用

配置 `pipeline.model_segmentation`：

- `auto`（默认）：ASR 来源启用，包括 URL 翻译复用已有 ASR 字幕的情况。
- `always`：已有本地 SRT/JSON 源字幕也启用。
- `off`：使用原有规范化和固定时间轴字幕输出流程。

例如在现有配置的 `pipeline` 中加入 `model_segmentation: always`，然后运行：

```sh
subtitle-llm translate --input input.srt --target-language Chinese --config config.yaml
```

`normalize_max_cue_chars`、`normalize_min_duration`、`normalize_max_duration` 在新模式中作为模型的阅读指导；不会用程序强行切分、合并或延长模型输出。`refine_translation` 不给新模式增加全片润色调用。已有人工字幕默认继续使用固定结构流程。

## 成本与恢复

- 原文只发送一次，模型只输出结束位置及译文，不复述英文、时间戳或断句理由。
- 保留全局摘要，只发送当前范围相关的术语与纠错；完整纠错证据保存在原上下文文件中。未知结构的用户自定义上下文保持完整。
- 翻译片段沿用输出预算约束及并发协调器，不按每条字幕调用模型。
- 空译文、无效位置和截断响应仅重试未完成范围；完整返回的结果保留。完全耗尽输出预算时不原样重试完整请求。
- 初次生成后，若现有数字检查发现本条缺失的数字出现在邻条，只将这个可疑范围交给模型重新决定边界和译文。每片段最多一次可选对齐修正，范围最多 120 个源文位置；与结构补齐共用每次执行最多两次追加请求的上限。它不按词典或长度规则改变切点。
- 对齐修正请求前保存尝试标记，网络失败或中断恢复不重复付费；响应不完整、数字仍缺失或出现新类型质量问题时保留原结果，进入现有质量检查/复核。结构补齐未取得进展时停止。以上调用上限针对模型断句阶段，后续既有自动质量修复或用户主动重译另计。
- 初始响应、局部补齐结果、已接受的复核结果和全局上下文存入任务的 SQLite 记录。请求键包含源文、时间、模型配置、协议和布局配置；恢复只复用一致的结果。
- 模型生成的内部编号使用源文位置；只在导出 SRT 副本时重编号，避免并发和恢复时将不同字幕混在一起。
- SQLite v2 升级到 v3 只增加结果表，保留已有任务。
- 新协议能精确读取同原文、时间、配置和上下文的 v1 缓存。已接受的旧字幕直接恢复；旧任务未完成的范围使用局部编号补齐，不重新请求已生成部分。

质量检查与 TUI 复核继续复用现有流程。初始断句由模型决定；进入复核后，修复重译仍针对当前时间轴字幕，只改变译文，符合 ADR-0001。人工合并结果也会缓存，恢复任务不会重复要求复核已接受的片段。

局部对齐修正发生在进入复核之前，是初次生成阶段的一部分。数字检查只能筛选候选，不代表完整的语义对齐检查；没有数字的错位仍可能漏检。模型选取的短语和阅读预算仍需复核，不能把“源文覆盖完整”当成“每条译文对应正确”。

新协议 trace 使用 `source_coverage` 记录全片范围、局部编号偏移、有效字幕数及覆盖缺口，`parse` 不再套用固定 cue 数。任务片段的 `diagnosis_json` 保留初始/复核前/最终诊断、是否经过人工复核以及 `accepted_with_issues`；用户按 `y` 后仍可追溯原始告警，后续状态保存和恢复不清空诊断或 trace 引用。

## 时间精度

当前 ASR 提供片段级时间戳，字幕切点仍按源文字符在片段内的位置插值。生成结果不会为了满足最短显示时间把后续字幕持续后移。这不等于获得了词级对齐：需要更高精度时应接入词级时间戳或强制对齐。

输出继续包含双语 SRT、模型切分后的源字幕和 `*_normalization_map.json`。映射同时记录原始 ASR 编号及源文位置范围，便于核对遗漏、重复与人工合并。

## 验证

`tests/test_model_segmentation.py` 覆盖原文重建、时间边界、独立短句、中日韩文字、局部补齐、截断响应、调用中断恢复、已复核合并恢复、费用计数、完整流水线及数据库升级。

离线比较使用同一种 tokenizer 估算新旧请求体；该结果不能直接视为供应商账单降幅。模型选型应比较相同视频片段的实际用量、总耗时、重试次数和人工复核量。

可复现的离线比较脚本（不调用模型）：

```sh
python scripts/benchmark_model_segmentation.py --input input.srt --context output_context.txt --config config.yaml --output benchmark.json
```
