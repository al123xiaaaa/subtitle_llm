# ASR backend migrates to FunASR llama.cpp / GGUF runtime

We replaced the Python `funasr` optional dependency with the prebuilt FunASR llama.cpp / GGUF runtime binaries (`llama-funasr-vad` + `llama-funasr-sensevoice`) and removed the PyTorch dependency entirely. We chose this over keeping a dual funasr/llama.cpp implementation because the llama.cpp path, once validated, removes the single heaviest and hardest-to-distribute dependency in the tool (PyTorch) without losing any capability.

The previous implementation called `funasr.AutoModel` directly and aligned timestamps to text by betting that the number of `<|lang|>`-tagged text segments equaled the number of VAD segments, falling back to collapsing everything into one entry when the bet failed. The new implementation takes timestamps and text from two independent sources that share the same `fsmn-vad.gguf`, so the segment counts are deterministically consistent (verified: 82 == 82 == 82 across runs on a 5-minute real audio track), and pairing is by index rather than by a fragile regex split. The `AsrBackend` protocol still lets us swap implementations or inject test doubles.

Trade-off accepted: users must now obtain the binaries and GGUF weights themselves (download from the Fun-ASR releases, run `download-funasr-model.sh sensevoice ./gguf`). This is documented in `default.yaml`. If the binaries are missing, `AsrError` gives a clear pointer to this ADR. The runtime's stdout carries no per-segment timestamps on its own; we get them by running the standalone `llama-funasr-vad` binary, whose stdout prints `start_ms end_ms` per line.

The text-side split uses an explicit set of SenseVoice segment-start tags (language codes plus `nospeech`) rather than a broad `<|[a-z]+|>` pattern. SenseVoice emits many in-segment tags (`<|EMO_UNKNOWN|>`, `<|Speech|>`, `<|Event_UNK|>`, `<|woitn|>`) that are lowercase but not segment starts; matching them would split a single VAD segment into several and break the 1:1 pairing with timestamps, collapsing the result via the fallback path. The explicit set was validated empirically (4 VAD segments == 4 text segments on a real 60-second track).
