# 素材版本与有界复核共用持久化工作区

状态：已采纳。依据：产品地图 #1 及 #2–#8 的最终决策。

素材库作为桌面入口。翻译任务继续负责执行与恢复，完整翻译版本负责内容身份，局部修改形成修订；源字幕变化、整部重跑和换模型接续创建独立任务。独立下载和转写只登记源素材，不伪造翻译任务。源字幕采用不可变副本，可靠素材身份由 Python 统一计算，桌面复用查询沿用同一规则。

ADR 0005 的 SQLite 归属与任务恢复约束继续有效。schema 版本 4 通过同一 `PRAGMA user_version` 迁移增加素材、版本、源文件、检查历史及预算表；升级前备份，迁移事务中断可回滚。跨任务表与素材表的内容同步集中在 `pipeline/workspace_storage.py`，工作区对派生、内容修改、保护及产物提供公共操作接口。

依据问题 #3 和 #4 对局部时间修复的明确授权，补充 ADR 0001：生成模型可以提出限定范围内的译文和时间候选，但必须通过结构、邻接与 Jev 验收；译文和时间调整分别记入历史、分别撤销。人工保留和编辑形成保护，不等于检查通过或翻译完整。依据变化时增加内容修订号，旧检查失效；在途请求必须校验其起始修订，不能把旧判断绑定到新内容。

首轮翻译和初检完成后，以可靠输入输出 token 用量的 30% 作为自动追加初始额度。摘要、估算用量、历史继承及额外处理不扩大该基准；每轮先预留核验、生成和验收。人工追加具有独立范围和额度。重新识别、相关翻译及验收在同一笔额度中完成，通过后创建带来源引用的版本；不得通过派生任务重新发放额度。

导出冻结开始时的字幕与修订，原子创建新路径，不能覆盖历史文件。字幕完整性、检查覆盖、任务执行和文件生成分别表达。部分导出明确标记未完成并保留原时间轴；检查缺失、服务失败或候选不确定不会强迫用户听音，也不会抹掉现有译文。

代价：为便于追溯保留更多快照与历史，数据库和文件会增长；此轮不自动删除历史。概率门槛只用于调度，不能被解释为真实正确率或费用保证。
